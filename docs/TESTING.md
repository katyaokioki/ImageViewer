# Сценарии проверки (для защиты проекта)

Автоматические тесты: `dotnet test tests/ImageViewer.Core.Tests` — все должны пройти.

Сценарии одинаковы для обеих графических версий: **Avalonia** (`ImageViewerX`, Linux/Windows) и **WPF** (`ImageViewer.exe`, Windows).
На Linux вместо `ImageViewer.exe` подставляйте `dotnet run --project src/ImageViewer.Avalonia --`, вместо `%AppData%` — `~/.config`.
Ниже — ручная проверка графического интерфейса. Подготовка тестовых файлов:

```powershell
dotnet run --project src/ImageViewer.Cli -- generate demo\images --count 12
```

Добавьте в `demo\images` 2–3 своих фото (JPEG с телефона — для проверки EXIF-поворота), PNG с прозрачностью
и один повреждённый файл (например, переименуйте `.txt` в `broken.jpg`).

## 1. Запуск и командная строка

| # | Действие | Ожидаемый результат | ✓ |
|---|---|---|---|
| 1.1 | `ImageViewer.exe` без параметров (первый запуск) | Окно с подсказкой «Откройте изображение…» | |
| 1.2 | `ImageViewer.exe demo\images\demo_3.bmp` | Открыт demo_3, полноэкранный режим, в строке состояния `3 / 12` | |
| 1.3 | `ImageViewer.exe demo\images` | Открыт первый файл папки | |
| 1.4 | `… demo_1.bmp --zoom 100 --windowed --info` | Окно, масштаб 100%, видна панель информации | |
| 1.5 | `… demo_1.bmp -t light -b checker` | Светлая тема, шахматный фон | |
| 1.6 | `… demo\images --slideshow 2 -n 5` | Начинает с 5-го, листает каждые 2 с | |
| 1.7 | `… --zoom huge` | Сообщение об ошибке параметров, затем приложение запускается | |
| 1.8 | `ImageViewer.exe --help` | Окно справки | |
| 1.9 | `… нет_такого_файла.jpg` | Всплывающее сообщение «Не удалось открыть…» | |
| 1.10 | Закрыть и запустить без параметров | Открывается последний просмотренный файл | |
